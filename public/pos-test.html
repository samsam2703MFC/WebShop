Page de test · mode boutique

La vraie vitrine est chargée ci-dessous avec un 3e mode « En boutique » (bleu) dans le sélecteur. Rien n'est modifié : aucun client ne voit ceci, aucune commande n'est créée.

Écran

Choisissez En boutique, ajoutez des produits, puis Afficher mon code caisse dans le panier. Le code est un vrai QR : scanné au téléphone, il affiche la liste du panier. Ce qui manque pour le vrai : une caisse qui sache le lire — ni le logiciel de caisse ni la console franchisé ne le savent aujourd'hui.
